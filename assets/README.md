# Icon Placeholder

The Electron application expects an icon file at `assets/icon.png`.

Since we can't include actual PNG files in this setup, you'll need to:

1. Add a PNG icon file to the `assets/` directory
2. Name it `icon.png` 
3. Recommended size: 256x256 pixels or larger

For now, the application will run without the icon, but you may see a warning in the console.
